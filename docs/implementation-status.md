# 功能实现与兼容性状态

| 功能 | 已有能力 | 尚需验证的部分 |
|---|---|---|
| HDM 安装器 | 版本化安装、交互终端自动进入菜单、旧版保留 | 各发行版权限与包管理器差异 |
| 终端菜单 | 10 个主菜单、475 个条目、双列/单列排版 | 非标准终端字符宽度 |
| 环境探测 | 桌面包、DRM 连接、X11/Wayland 会话 | DRM 连接不等于真实图形输出 |
| Xorg Dummy | 软件包安装、分辨率配置、备份与恢复 | 图形服务真实运行及远控捕获 |
| Xvfb / VKMS | 运行参数、服务管理及内核能力检查 | 与桌面和远控程序的端到端协同 |
| GNOME / GDM3 | 完整桌面安装、服务和会话诊断 | 无 GPU、Wayland、重启后无人值守 |
| RustDesk | 官方包安装、ID 查询、服务器设置、双账户 TOML 读回验证 | ID 注册和实际图形连接 |
| 更新与回滚 | 版本检查、固定提交归档、安全结构检查、旧版保留 | 更多服务器环境中的升级恢复 |
| 故障诊断 | 软件源/网络/磁盘/图形服务错误分类，受控日志输出 | 特殊环境下的自动修复范围 |

**说明：** 系统组件安装成功不等于图形会话或远程画面可用。检查结果按实际证据显示，不用菜单标签替代运行验证。
