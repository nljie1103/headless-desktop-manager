## 云服务器验收要求

1. Ubuntu 24.04 x86_64，留存 SSH 和云救援控制台快照。
2. Xorg Dummy 与 GDM3/X11 能启动，GNOME Shell 使用真实 GUI 会话，而不是仅存在进程。
3. RustDesk 设备 ID 注册成功、远程画面完整、鼠标键盘可操作。
4. 自建 ID/中继、公钥、永久密码登录要实测。
5. 重启后重新连接，配置错误能通过恢复机制解除。

未达到上述要求不得将 v0.3.1 标记为生产稳定版。
