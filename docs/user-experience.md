# HDM 菜单、安装输出与配置验证规范（v0.3.2）

1. **主菜单保留十项**，全部原有 473 个条目保留；交互终端默认清屏避免无限刷屏，非 TTY 和 `HDM_NO_CLEAR=1` 不发送清屏控制码。
2. **系统软件包操作静默**：APT/DNF/YUM 正常安装时只显示步骤和成功；完整日志落在 `/var/log/hdm/operation-*.log` 并设置 `0600` 权限。`HDM_DEBUG_INSTALL=1` 可切换详细输出。
3. **错误分类必须有证据**：日志含磁盘不足/签名/超时/DNS/404/依赖冲突等信息时给出对应描述；未知错误输出退出码和日志路径。不能猜测失败原因，不能用换源绕过签名或依赖错误。
4. **RustDesk 配置是独立动作**：7.1.1 创建受保护的待应用草稿，7.1.2/3 独立修改，7.1.6 只读预览，7.1.7 执行导入与 root CLI 配置读回检查，7.1.8 只查询 `rustdesk --get-id`；7.3 只读检查作用域，7.9 使用已保存地址测试网络。
5. **RustDesk 配置文件校验只是静态读回**：即使文件里的 ID、Relay、公钥一致，也不能宣称 RustDesk 后台进程已采用配置或服务器已成功注册。外部连接和画面捕获仍需从另一台机器实测。
6. **Ubuntu 26 GNOME Wayland-only**：菜单必须明确标记 Xorg Dummy 仅用于独立 X11 测试，不可再称其为 GNOME Wayland 推荐虚拟显示方案。无显示器登录和 RustDesk 的 ARM64 无人值守仍待验证。
7. **危险变更需要确认**：该版本只减少安装日志和重复字段输入，不取消破坏性操作的确认、回滚或软件包签名校验。
