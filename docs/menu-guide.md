# HDM v4.4.1 · 简洁菜单指南

HDM 的主菜单保持八个入口：前七个与顶部桌面链路对应，第八个管理 HDM 自身。常用操作**直接执行**，不再先让用户选择“预览”或在“正式版 / main”之间做选择。

```text
1. 显示输出管理              5. 图形会话管理
2. 登录管理器管理            6. RustDesk 管理
3. 图形协议管理              7. 设备 ID 与设备信息
4. 桌面环境管理              8. HDM 脚本管理
```

## 直接使用

| 目的 | 菜单路径 |
|---|---|
| 安装 GDM3 | **2 → 1 → 1** |
| 安装 LightDM | **2 → 1 → 2** |
| 卸载 GDM3 | **2 → 2 → 1** |
| 卸载 LightDM | **2 → 2 → 2** |
| 更新当前登录管理器 | **2 → 3 → 1** |
| 选择默认 LightDM | **2 → 5 → 1**（系统登录管理器选择界面） |
| 安装完整 GNOME | **4 → 1 → 1** |
| 安装 XFCE + Xorg + LightDM | **4 → 1 → 2** |
| 安装 MATE + Xorg + LightDM | **4 → 1 → 3** |
| 卸载 GNOME / XFCE / MATE | **4 → 2 → 1/2/3** |
| 更新桌面 | **4 → 3** |
| 安装 / 卸载 / 更新 RustDesk | **6 → 1/2/3** |
| 配置 RustDesk 的 ID、Relay 与 Key | **6 → 4** |
| 查看设备 ID / 系统架构 | **7 → 1/3** |
| **更新 HDM 最新正式版** | **8 → 1** |
| **卸载 HDM（保留数据）** | **8 → 2** |
| 查看更新日志 / 安装日志 / 导出日志 | **8 → 3/4/5** |
| 旧版本回滚、指定版本和 main 开发分支 | **8 → 10**（高级维护） |

安装、卸载和更新均没有额外的独立“预览”步骤。需要避免损坏系统时，APT 会在后台自动模拟删除依赖，并检查不应删除的关键组件。破坏性删除只询问**一次**，随后执行真实 `apt-get remove -y`；不会默默做 `purge`、`autoremove` 或重启。

## Ubuntu 26 ARM64：先卸载旧桌面，再安装新的

HDM 现在允许按用户选择的顺序操作，不强制先安装 LightDM。

1. 在**独立 SSH 或云控制台**中进入 `sudo hdm`，并预备可恢复的机器快照。
2. 选择 `2 → 2 → 1` 卸载 GDM3。程序会列出 APT 将移除的包，**只要求一次确认**。确认后真的卸载，正在运行的图形登录界面可能立即消失。
3. 选择 `4 → 2 → 1` 卸载 GNOME。卸载后暂时没有图形桌面属于正常中间状态；必须保持 SSH/控制台可用。
4. 选择 `4 → 1 → 2` 安装 XFCE、Xorg、LightDM 和 GTK 登录界面。
5. 如需切换默认登录管理器，选择 `2 → 5 → 1`。这会调用系统交互式选择界面，不再额外问一次确认。
6. 安排安全重启后，检查 `sudo hdm --chain`，从另一台机器实际测试 RustDesk 登录、画面和输入。

也支持先装新的、验证后再卸载旧的顺序。两种操作模式都不会被人为禁止。

**注意：** 从活动桌面/RustDesk 窗口执行卸载可能使连接立即断开，影响正在执行的 APT 操作。这是卸载活动图形栈的真实风险，不是菜单缺陷。HDM 不会保证失去唯一远程连接后仍能恢复，请使用独立 SSH/云控制台。

## 保护范围和高级功能

- APT 的只读依赖模拟属于卸载流程的内部检查，不再占用日常菜单编号。如果模拟发现会额外移除 RustDesk、Xorg、OpenSSH、systemd、APT 或当前操作目标以外的登录管理器，HDM 仍会拒绝执行。
- 更新 HDM 只使用**最新正式 Release**，自动支持 GitHub API 同资产 SHA256 备用下载。main 开发提交和历史版本回滚保留在高级维护里，不与正式更新并排。
- HDM 自身卸载只解除管理器命令与当前版本链接，保留配置、操作日志、历史版本和所有系统桌面软件。
- 完整历史功能保存在 `ui/legacy-menus.tsv`，经 `ui/menu-targets.tsv` 明确路由。修改菜单必须同步 `scripts/build-menus-v2.py` 和测试。
- 顶部七节点颜色仅表示**本机检测**，不能据此宣称 RustDesk 外部画面已经成功。
