# HDM 中文菜单指南

HDM v4.0.0 保留 10 个主菜单入口和既有动作路由，使用紧凑的状态栏及横线分区。终端够宽时以双列显示，窄终端单列排列；子菜单按短编号左对齐。

```text
  ─────────────────────────────────────────────────────────────
  HDM v4.0.0  ·  ubuntu 24.04 / x86_64
  桌面包 GNOME  ·  会话 x11  ·  RustDesk 1.5.1
  ─────────────────────────────────────────────────────────────
  1. 安装虚拟显示器                6. 更新 RustDesk
  2. 管理显示与分辨率              7. RustDesk 连接配置
  3. 安装桌面环境                  8. 更新 HDM 管理器
  4. 管理桌面与会话                9. 智能安装与续装
  5. 安装 RustDesk                 10. 系统诊断与日志
  ─────────────────────────────────────────────────────────────
  0 / q 退出
  请选择 >
```

*内容是排版示意；实际系统与状态信息会实时读取。* 根菜单 `0` / `q` 退出；子菜单 `0` 返回上一级、`q` 退出；`hdm --menu-tree` 查看全部菜单编号。

## 常用入口

| 菜单 | 主要用途 |
|:---|:---|
| 1 / 2 | 安装与管理虚拟显示器，检查驱动、状态、分辨率和快照 |
| 3 / 4 | 安装与管理 GNOME、其他桌面、GDM3、图形会话 |
| 5 / 6 | RustDesk 安装、更新与版本维护 |
| 7 | ID 服务器、中继、公钥、密码及权限检查 |
| 8 | HDM 管理器在线检查、升级、回退 |
| 9 | 按主机环境生成安装计划与中断续装 |
| 10 | 系统体检、日志、诊断包和配置恢复 |

- `7 → 1 → 1`：录入 ID / 中继 / 公钥草稿；`7 → 1 → 6`：只读预览；`7 → 1 → 7`：保存并校验。
- `4 → 图形会话管理`：独立检测 GDM3 服务、GNOME 用户会话、桌面协议、D-Bus 与日志。
- `10 → 日志查看 → 导出诊断包`：汇总仍可取得的 HDM、APT、GDM3、RustDesk 日志。

**启动 GDM3 ≠ GNOME 用户会话已建立；现有 XFCE X11 会话也不能替代 GNOME。** Ubuntu 26 GNOME Wayland 环境下不要强制设置 `WaylandEnable=false`；登录前与锁屏应分别验收。详见 [Ubuntu 26 ARM64 指南](ubuntu26-arm64.md)。
