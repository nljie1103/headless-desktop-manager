# HDM · 六类常用菜单指南（main 开发分支）

普通用户不用逐项选择 DRM、Xorg、会话、Greeter 和协议。**需要一套可用的桌面，只选择一个桌面环境及与它配套的登录管理器**。独立安装桌面时不会捆绑登录管理器；只有选择“快速部署”才会补齐整套依赖。DRM/KMS 是内核显示层，Xorg 是 X11 服务器，LightDM 是登录管理器，XFCE 是桌面；它们不在同一层级。

## 哪些二选一？哪些必须配合？

- **LightDM / GDM3** 属于登录管理器。通常只需要一个被选为默认并运行，不要同时启动它们争夺显示 seat；LightDM 常配 XFCE/MATE，GDM3 常配 GNOME。
- **XFCE / GNOME / MATE** 属于桌面环境。选一个主要桌面即可。XFCE 本身不是独立常驻 systemd 服务，不应该人为增加“启动 XFCE 服务”按钮。
- **Xorg / X11、Wayland** 是图形服务器和协议。Ubuntu 26 GNOME 采用 Wayland；XFCE/MATE 可选 X11。Xorg 通常由登录管理器按需启动。
- **DRM/KMS 与 Xorg 不是二选一**。DRM/KMS 提供内核显示能力；Xorg 使用其输出。只有没有可用输出时，才根据实际需要考虑 Xorg Dummy、VKMS 或 Xvfb，不需要全部安装。
- **RustDesk** 是独立远控软件，有自己的 systemd 服务，支持启动、停止、重启和自启。

## Ubuntu 26.04 ARM64 建议操作顺序

例如一台 `Virtual-1 connected`、已装 Xorg/LightDM/RustDesk，却没有 XFCE、LightDM 当前 `inactive` 的云主机：

1. 通过独立 SSH 或云控制台打开 `sudo hdm`，确保能在远控断开时恢复。
2. 选 **`2 → 1` 仅安装 XFCE**（不重复安装 LightDM）；或者 `1 → 2` 预览自动部署计划、`1 → 1` 确认安装。
3. 选 **`3 → 12` 查看默认登录管理器**；若不是 LightDM，可经 `3 → 11 → 1` 交互切换。
4. 选 **`3 → 3` 启动 LightDM**；选 **`3 → 6` 设置开机自启**。两个动作独立。
5. 使用 **`2 → 9 → 4`** 检查实际 Xorg/X11 会话，最后从另一台机器测试 RustDesk 画面、键鼠、锁屏、注销、重启后的登录界面。**服务 active 不保证远端可控**。

如果 LightDM 启动失败，优先使用 **`6 → 3` 诊断**，或在 SSH 中执行：

```bash
systemctl status lightdm --no-pager -l
sudo journalctl -b -u lightdm -n 80 --no-pager
ls /usr/share/xsessions/
```

不要因为 `installed + inactive` 就直接删除 LightDM、DRM 或容器数据。

## 图形会话管理（菜单 2 → 9）

| 操作 | 路径 | 说明 |
|---|---|---|
| 查看登录界面及用户会话 | `2 → 9 → 1` | 显示 LightDM/GDM3、Xorg、登录用户会话；不会把 SSH 计为图形会话 |
| 新建图形会话入口 | `2 → 9 → 2` | 检查桌面、Greeter 和 Xorg，确认后启动登录界面；用户输入密码后才创建真实图形会话 |
| 查看指定会话详情 | `2 → 9 → 3` | 输入列表中的 ID，核实身份后读取 logind 属性 |
| 结束指定图形会话 | `2 → 9 → 4` | 安全注销，不删除用户或桌面文件，可能丢失该桌面未保存的数据 |
| 选择默认 X11 桌面 | `2 → 9 → 5` | LightDM 已安装 XFCE/MATE 时可选择默认会话 |
| 查看 X11/Wayland/Xorg | `2 → 9 → 6` | 显示协议与已安装会话，而不是切换 DRM |
| 查看登录界面日志 | `2 → 9 → 7` | 读取当前默认管理器的 systemd、Xorg 和 LightDM 日志 |

**HDM 不会从 SSH 绕过 PAM 创建已认证的桌面会话，也不会默认启用自动登录。** LightDM 启动后的 greeter 与用户登录后的 XFCE 会话是两种不同状态。`5 → 1` 可直接查看 DRM/KMS 连接器（例如 `card0-Virtual-1`）、Xorg、LightDM 及真正的图形用户会话。

**v4.5.1 的“会话超限”来自只扫描前 24 条 loginctl 记录。v4.5.2 起扫描最多 256 条并只统计图形用户会话。** v4.5.3 进一步区分登录界面与真实已登录桌面。

## 安全与版本

- 关闭/重启图形登录管理器或 RustDesk 会影响当前远控。HDM 对这些操作需要确认；卸载 APT 包先模拟受影响的依赖、阻止删除受保护系统组件。
- 自启 `enable` 不会立即启动服务；禁用 `disable` 不会自动停止正在运行的服务。
- 需要更细的日志和协议排障时使用 `hdm --doctor`、`hdm --chain`、`hdm --readiness`，而不是在常用菜单里层层进入诊断子菜单。
- **本指南对应 v4.5.3。** v4.5.1 保留八模块旧菜单；在旧版使用 `8 → 1` 更新到最新正式版本，更新后本菜单的 HDM 更新入口为 `6 → 1`。
- 子菜单按 `0/q` 返回，主菜单 `0/q` 退出，`Q` 任意层直接退出。卸载 HDM 会保留软件、历史版本、配置和日志。
