全菜单共有 74 个条目、63 个操作，最多三级。无需把 DRM、Xorg、LightDM、XFCE、X11 或 Wayland 混成同类组件。DRM 是内核显示输出；Xorg 提供 X11，Wayland 是另一种图形会话协议。

## 如何选择图形协议

Ubuntu 26.04 ARM64 上，XFCE/MATE 适合 X11 + LightDM。先确保桌面已安装，在 3 → 2 选择实际存在的 XFCE/MATE X11 会话。此操作更新 LightDM 的默认会话，不会注销当前桌面。

GNOME/Wayland 需要先安装 GNOME 和 GDM3，并有已安装的 Wayland 会话文件；在 3 → 3 选择 GDM3 默认登录管理器后，再从 GDM3 登录界面选择 GNOME Wayland 并输入密码。更改默认登录管理器不会直接把正在运行的 X11 桌面转为 Wayland，也不会将 DRM 变为 Wayland。不要强行给 Ubuntu 26 GNOME 恢复已不支持的 Xorg 会话。

## 图形会话操作

图形会话只管理真实的 X11/Wayland 用户登录。5 → 1 查看会话，5 → 2 启动登录入口（仍需密码认证），5 → 3 查看已存在的会话详情，5 → 4 选择会话并安全注销。SSH、TTY 和未登录的 Greeter 不作为普通用户图形会话；结束会话并不删除账号或文件。

登录管理器运行状态请看 2 → 12，登录界面启动日志在 2 → 13，协议状态仅在 3 → 1，不再在会话菜单重复提供。设备 ID 和中继服务器配置归入 7。

## 确认与安全

菜单中明确选择安装、升级、启动及自启开关即视为授权，避免多次询问 y/N。快速部署在展示完整计划后可要求一次确认；卸载通过 APT 模拟和 remove/purge 选择保护系统配置；停止/重启登录管理器、RustDesk、注销用户桌面等可能切断远程连接的操作保留安全确认。独立 SSH / 云控制台应保持可用。

详细状态仍可通过 hdm --chain、hdm --readiness、hdm --doctor 查询。服务运行不等于远端 RustDesk 已能捕获登录界面或锁屏。v4.5.5 用户从旧菜单 6 → 1 更新到新版本；v4.5.6 以后更新入口为 8 → 4。
