# HDM 菜单指南

HDM 有 10 个主菜单，依次负责虚拟显示安装/管理、桌面安装/管理、RustDesk 安装/更新、服务器配置、HDM 更新、一键安装和故障诊断。主菜单保持双列或单列自动布局，各级子菜单名称尽量简短。

`0` 返回上级，`q` 退出。导航编号和对应动作不随显示名称缩短而改变；全部条目见 `hdm --menu-tree`。

## 常用路径

- `7 → 1 → 1`：输入 ID、中继、公钥，保存草稿；`7 → 1 → 6`：完整查看；`7 → 1 → 7`：备份、保存并核验；`7 → 1 → 8`：查询设备 ID，不重复填写配置。
- `7 → 3`：读取已经保存的 ID、Relay 和完整公钥。**查看公钥需要可信终端，避免在公开日志里粘贴完整设置。**
- `8`：管理器更新、历史版本与回滚。
- `9`：按本机环境安装所需组件，支持中断续装。
- `10`：检查故障、查看日志、管理软件源与备份。

## 状态的含义

“软件包已安装”“显示输出已连接”“图形会话可用”“RustDesk 设备 ID 存在”和“远程画面可控”互不等价。HDM 分别显示可取得的事实；无法直接验证的连接结果需要另一台设备执行实际连接。


## 图形会话与排错日志

- `4 → 管理图形会话`：独立检查服务/协议/登录用户/日志；支持尝试启动 GDM3、可用时的 VKMS 临时修复以及设置开机图形目标。
- `2 → 查看显示环境详细状态`：驱动版本、显示服务、分辨率日志各有独立实现，不再重复展示同一张状态表。
- `10 → 日志查看 → 一键导出完整诊断包`：生成 `.tar.gz`，包含 HDM 操作日志、APT/dpkg 安装记录以及图形和远控系统日志。
- `sudo hdm --session-status`、`sudo hdm --session-start`、`sudo hdm --session-repair`、`sudo hdm --export-diagnostics` 提供直接命令入口。

安装成功只表示软件包完成部署；服务正常、登录的桌面会话和外部 RustDesk 画面必须分别确认。
