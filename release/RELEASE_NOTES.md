- 修复 HDM v4.4.0 通过正式 Release 菜单更新后，因 tar 解压文件权限受严格 umask 影响，导致 `sudo hdm` 报找不到命令的问题。
- 两种升级渠道在切换当前版本前都会恢复脚本执行权限和源码目录访问权限；权限检查未通过时拒绝切换，原版本保留。
- 增加在 umask 077 条件下模拟正式归档安装、检查 `hdm.sh` 可执行和版本链接，以及 main 固定提交归档同等安全回归。
- 保留 v4.4.0 新的少层级菜单：支持先卸载 GDM3/GNOME 再安装 XFCE/LightDM，实际删除只问一次且继续保护 RustDesk、SSH、Xorg 等关键依赖。
- 如果已升级到 v4.4.0 且 `sudo hdm` 找不到命令，可先通过 SSH/控制台执行 `sudo chmod 755 /opt/hdm/current/hdm.sh` 恢复，再从菜单 `8 → 1` 更新至最新正式版。
