- 解决 GDM3、GNOME 等卸载菜单仅显示只读模拟的问题，新增真正的 APT 软件包卸载入口，保留操作预览与独立确认。
- 在卸载活动登录链路前检查替代管理器是否被选为默认并已真实运行、XFCE/MATE 会话包和 Xorg 是否安装，以及 GNOME 是否仍有活动会话；条件不满足时明确拒绝删除。
- 真实卸载先执行 APT 完整模拟，禁止连带删除 RustDesk、Xorg、SSH、系统基础组件和未选择的替代桌面，确认后再执行 `apt-get remove -y`，不自动 purge、autoremove 或重启。
- 新增在菜单中交互式切换 GDM3/LightDM 默认管理器的选项（系统 dpkg-reconfigure）；切换选择不等于当前服务已经重启。
- 测试包含取消确认、受保护依赖阻断、真实 APT 命令调用、桌面会话检测；未在生产图形会话上执行破坏性卸载。
